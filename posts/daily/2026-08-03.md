# 📋 今日要闻速览

今日科技圈迎来重磅发布日：阿里巴巴正式开源 Qwen3.8（总参数量 2.4 万亿），在 Arena 榜单中仅次于 Claude 系列；MiniMax 同日开源通用视频模型 H3，支持 2K 分辨率 + 原生立体声 15 秒视频生成。游戏行业则迎来史上最大规模收购——沙特 PIF 以 550 亿美元收购 EA，将于明日（8月4日）正式完成。OpenAI 下一代模型 Astra 以约 2000 美元算力成本破解十项数学难题，AI 数学推理能力再获突破。此外，AI Agent "自我进化"趋势持续深化，从被动工具向主动出题、自我反思的新阶段演进。

## 🤖 AI 前沿

### 【阿里巴巴正式发布 Qwen3.8】阿里巴巴于 8 月 3 日正式发布新一代基座大模型 Qwen3.8，总参数量达 2.4 万亿，在编程（Coding）和专业办公（Cowork）方面能力大幅提升。在三方榜单 Arena 中，阿里 Qwen 模型仅次于 Anthropic 的 Claude 系列。目前 Qwen3.8 的 API 已上线千问 AI 平台，并同步接入企业级 Agent 产品"千问办公"。Qwen3.8-Max 预计下周开源，届时还将开源 Qwen3.8-27B。

我的分析：Qwen3.8 的发布标志着中国大模型能力已逼近全球第一梯队。从参数量 2.4 万亿来看，这已是超大规模 MoE 架构的典型代表。值得注意的是阿里选择了"API先行+分阶段开源"的策略——先让市场验证能力，再通过开源 27B 版本构建生态护城河。这种打法既保证了商业化收入，又兼顾了开源社区影响力，对 Anthropic 和 OpenAI 均构成实质性竞争压力。

### 【MiniMax H3 正式开源】36氪获悉，MiniMax 正式开源新一代通用视频模型 MiniMax H3，这是一个通用型全模态生成系统，能够统一理解由文本、图像、视频和音频构成的多模态上下文，并可生成最高 2K 分辨率、最长 15 秒、带有原生立体声音频的视频。

我的分析：MiniMax H3 的核心突破在于"原生立体声音频+多模态统一理解"，这解决了过往 AI 视频"有画面无声音"或"声音与画面割裂"的痛点。更值得关注的是其"全模态"定位——不同于专注单一模态的竞品，H3 试图用统一架构处理所有输入输出形式，这代表了多模态 AI 的重要发展方向。开源策略也将进一步降低视频 AI 的应用门槛。

### 【OpenAI Astra 以 2000 美元算力破解十项数学难题】OpenAI 当地时间 8 月 1 日发布数学和理论计算机科学的十项突破，这些成果由其下一代主要模型 Astra 的内部版本实现。按照 Sol API 的费率计算，找到这些问题的解决方案所需总词元成本约为 2000 美元。十项突破涵盖高维球体堆积密度上限、二进制与球面码界限提升、非纯索菲群存在性证明、康涅斯刚性猜想的推翻、算术电路复杂性新下界、量子平行重复定理等多个方向。

我的分析：2000 美元破解十项数学难题，平均每项仅 200 美元——这个成本在数学研究领域实际上是极低的。传统数学家攻克一个猜想往往需要数年时间，而 Astra 在极低成本下实现批量突破，证明了 AI 在形式化数学推理方面的潜力已远超人类直觉。这一进展对数学研究范式具有深远意义：AI 不再只是辅助工具，而开始成为独立的问题解决者。同时，这也意味着 AI 安全问题变得更加紧迫——具备超强推理能力的系统若缺乏对齐，其风险等级将显著上升。

### 【AI Agent 开启"自我进化"模式】据 Lumina 订阅流，多篇文献显示 AI Agent 正从被动工具向主动智能体演进：腾讯技术工程分析了 Agent 自进化的三条路线（经验/Skill 存储、RL 权重训练、零数据自学），指出 Agent 已具备"会出题、会反思、还会自己长出新技能"的能力；另有研究梳理了经验总结者被系统性低估的现象，认为未来关键在于同时实现自主出题与可训练总结者。

我的分析：AI Agent 的自我进化是 2026 年最重要的技术趋势之一。传统 Agent 依赖预设 Skill 和人工编排，而新一代 Agent 开始具备自我反思、自主出题和增量学习的能力，这意味着 AI 系统可以在部署后持续自我优化而无需人工干预。如果这一趋势持续发展，未来 AI Agent 将从"被设计的工具"转变为"可自主成长的助手"，对软件开发、工作流程自动化等领域将产生颠覆性影响。同时，如何确保自我进化过程中的安全可控，也是需要严肃面对的课题。

### 【OpenMontage：开源智能体视频制作工具】Lumina 订阅流收录了 OpenMontage，这是一个以开源 agentic 管线解决 AI 视频工具只能生成片段问题的项目，可用自然语言端到端完成研究、脚本、素材、剪辑与渲染，并通过质量、预算和审计机制支持低成本完整视频生产。

我的分析：OpenMontage 的核心价值在于将 AI 视频制作从"片段生成"升级为"完整作品生产"。传统 AI 视频工具只能生成零散的短片段，而 OpenMontage 通过 agentic 管线实现了从创意构思到最终成片的全流程自动化。这意味着内容创作者可以用自然语言描述需求，AI 自动完成从选题研究到剪辑渲染的全部工作。这对短视频创作、广告制作和教育内容生产等领域具有重要的效率提升意义。

## 📊 行业动态

### 【沙特 PIF 以 550 亿美元收购 EA，预计明日完成】据欧盟委员会文件，沙特阿拉伯主权财富基金（PIF）与投资者财团已获欧盟批准以 550 亿美元收购全球电子游戏开发巨头艺电（EA）。EA 确认截至 7 月 30 日已获得所有必要监管批准，并预计该交易将于 8 月 4 日正式完成。

我的分析：这是游戏行业史上最大规模的收购案之一，也是沙特 PIF 在游戏领域的又一次重磅布局。此前 PIF 已投资动视暴雪、Take-Two 等多家游戏巨头，此次收购 EA 将使沙特主权基金成为全球游戏产业的重要控制者。从地缘政治角度看，沙特正在通过"2030愿景"积极推进经济多元化，游戏产业作为数字娱乐的核心组成部分自然成为重点投资方向。对 EA 而言，被主权基金收购可能带来战略方向的调整，需持续关注。

### 【我国牵头的区块链国际标准在 ISO 成功立项】记者了解到，由我国牵头的国际标准《区块链和分布式记账技术 区块链即服务的技术框架和功能要求》近日在国际标准化组织（ISO）成功立项。德国、英国、爱尔兰、日本、葡萄牙、乌干达等国将派员参与制定。

## 📌 本日总结

1. **大模型开源战加剧**：Qwen3.8 和 MiniMax H3 同日开源，标志着中国 AI 厂商在开源领域的竞争进入白热化阶段。Qwen3.8 在 Arena 榜单逼近 Claude，MiniMax H3 以全模态视频模型差异化突围，两者共同推动中国 AI 开源生态迈向全球前列。

2. **AI 推理能力再获突破**：OpenAI Astra 以极低成本破解十项数学难题，证明了 AI 在形式化推理方面的能力已远超传统认知。这不仅对数学研究范式产生深远影响，也使 AI 安全对齐问题变得更加紧迫。

3. **AI Agent 从工具向自我进化体演进**：新一代 Agent 开始具备自主出题、自我反思和增量学习的能力，不再依赖预设 Skill 被动执行任务。这一趋势若持续发展，将重新定义 AI 在工作流程中的角色。

4. **跨境金融合作持续深化**：中韩金融监管部门联合推出务实合作举措，港交所中国国债期货上市，反映了中国金融市场对外开放的坚定步伐，同时也为全球投资者提供了配置中国资产的新渠道。

5. **地缘政治影响产业格局**：沙特 PIF 以 550 亿美元收购 EA 的交易即将完成，标志着主权基金正在重塑全球游戏产业格局；苹果涨价预期和韩国杠杆产品监管新规则反映了消费电子和金融产品领域正在经历结构性调整。
